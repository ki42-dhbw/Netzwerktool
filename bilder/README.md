# Eigene Bildbibliothek

Hier können eigene JPG-, JPEG-, PNG-, WebP-, GIF- oder SVG-Dateien abgelegt
werden. `node build.js` bettet unterstützte Bilder direkt in die erzeugte
Offline-Anwendung ein.

Das öffentliche Ausgangspaket enthält keine Produktfotos, weil dafür keine
Veröffentlichungsrechte dokumentiert sind. Vor einem Commit Herkunft, Lizenz
und mögliche vertrauliche Bildinhalte prüfen.
