# Sicherheitsrichtlinie

Sicherheitsprobleme bitte über eine private GitHub Security Advisory des
Repositories melden, sofern diese Funktion aktiviert ist. Keine Zugangsdaten,
produktiven Netzwerkpläne oder unveränderten Scan-Dateien in öffentliche Issues
einfügen.

Ein Bericht sollte betroffene Version, reproduzierbare Schritte, erwartetes und
tatsächliches Verhalten sowie mögliche Auswirkungen enthalten. Beispieldaten
vorher vollständig anonymisieren.
